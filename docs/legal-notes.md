# 第三者向けの寄付を集める際の注意点（Lumiere Conseil の新規事業）

このメモは設計判断のための整理です。法的助言ではありません。公開前に弁護士・税理士に確認してください。内容は 2026年10月時点の一般的な理解に基づく推測を含みます。

## 0. 運営主体：Lumiere Conseil（個人事業の屋号）

Lumiere Conseil は個人事業の屋号です（Masa の回答、2026-10-13）。法的には個人運営と同じ扱いなので、以下の注意点がそのまま当てはまります。

- **特商法表記**：事業者名は「Lumiere Conseil（個人事業）」とし、運営責任者の氏名は記載が必要です。住所と電話番号は「請求があれば遅滞なく開示」とする方法を使っています（`/legal`）。【氏名】を埋めてください。
- **Stripe の申請**：事業形態は「個人事業主」で申請し、屋号に Lumiere Conseil を設定します。本人確認書類と、事業内容の説明（寄付プラットフォームであること、Connect で受取先へ直接入金し運営者は寄付金を預からないこと、手数料 10%）が必要です。個人事業主の Connect プラットフォームは審査が厳しくなる可能性があるため、審査で難しいと言われた場合は法人化（合同会社など）を検討してください。
- **税務**：事務手数料は Lumiere Conseil の事業所得です（開業届・青色申告の確認を推奨）。寄付金そのものは受取先に直接入金されるので、Lumiere Conseil の売上にはなりません。年間の課税売上が1,000万円を超えると消費税の課税事業者になります（月100万円の手数料収入なら到達します）。

## 0.5. 調査結果を受けた設計（2026-10-13）

- このサイトで決済するのは **審査済みの日本国内の法人（社会福祉法人・NPO法人・公益法人など）だけ**。個人への寄付は扱わない（Stripe の禁止業種で、資金移動業の懸念もある）。
- **自治体**：第三者が公金を収納するには「指定公金事務取扱者」の指定が必要なため、当面は自治体の公式寄付ページ（ふるさと納税など）へのリンクで掲載する。
- **義援金**：日本赤十字社など公式窓口へのリンクで掲載する。
- **海外の寄付先**：日本の Stripe アカウントは海外へ入金できないため、GlobalGiving など海外プラットフォームへのリンクで掲載する。
- **収益**：お支払い額の 10% を事務手数料として受け取る（Masa の決定、`PLATFORM_FEE_PERCENT`）。Stripe Connect の application fee として Lumiere Conseil に入り、カード決済手数料（約3.6%）はこの中から負担する。
- **手数料の寄付者負担**：寄付フォームの「事務手数料も負担する」（初期値オン）で、手数料分を上乗せして受取先に全額届ける。初期値オンは成長戦略スレッドの提案。寄付者が誤認しないよう、内訳（お支払い額・受取先へ・手数料）をフォームに常時表示している。
- **災害の緊急支援**：受取先に `emergency` と `feePercent: 5` を設定すると、トップに「いま支援が必要な災害」として表示され、手数料が 5% になる。
- **注意**：10% は寄付プラットフォームとしては高めの水準。寄付ページと「寄付金の流れ」ページで手数料を明示している（景品表示法・寄付者の誤認防止の観点からも明示は必須）。

## 1. 寄付金を運営者が預からない（最重要）

個人が寄付者からお金を受け取り、あとで自治体や施設に送る形は、次のリスクがあります。

- **資金移動業（資金決済法）に当たる可能性**：他人のために送金を仲介する行為は、登録なしでは違法になりうる。
- **横領・詐欺の疑いを持たれやすい**：個人口座に多額の寄付が集まると、信頼面でも税務面でも説明が難しい。
- **運営者の所得とみなされる可能性**：一度個人が受け取ると、課税関係が複雑になる。

このため、サイトは **Stripe Connect で寄付金を受取先自身の Stripe アカウントへ直接入金する** 前提で作っています（`lib/recipients.ts` の `stripeAccountId`）。運営者は手数料（任意、既定 0%）だけを受け取ります。

受取先が Stripe アカウントを持てない場合（自治体、海外の団体、被災者個人など）は、**公式の寄付窓口へのリンクに留める** 設計にしました（`lib/recipients.ts` の `payment.mode = "external"`）。

## 2. Stripe の規約

- 寄付・募金の受付は Stripe の審査対象になりやすく、事業者情報、受取先との関係、資金の流れの説明を求められます。
- 個人アカウントで「他人のための寄付」を集めると、アカウント停止や入金保留になる可能性があります。Connect のプラットフォームとして登録し、受取先ごとに本人確認（KYC）を通す形が筋です。
- Connect で日本と海外の受取先をまたぐ場合、国ごとに対応可否や送金方式（クロスボーダー送金の制限）が異なります。**海外の受取先は国ごとに Stripe の対応状況を確認** してください。
- 本番キーを使う前に、Stripe に事業内容（寄付プラットフォーム、資金は受取先に直接入金）を説明して承認を得てください。

## 3. 寄付金控除（税）

- 控除の対象かどうかは **受取先** で決まります。自治体（ふるさと納税を含む）、認定NPO法人、公益社団・財団法人、社会福祉法人の一部などが対象です。
- **領収書は受取先が発行** します。個人運営のプラットフォームは控除用の領収書を出せません。
- ふるさと納税として扱うには、自治体側の手続き（ワンストップ特例など）が必要です。自治体の公式ポータル連携を検討する価値があります。
- 海外の受取先への寄付は、日本では原則控除対象外です。

## 4. 被災者個人への寄付

- 個人への直接送金は本人確認と悪用防止が難しく、また寄付が「贈与」とみなされる場合があります。
- 原則として **自治体・都道府県の義援金窓口、社会福祉協議会** を受取先にしてください。

## 5. 表示・個人情報

- 特定商取引法の表記：寄付は商取引ではないため必須かは議論がありますが、Stripe 審査や信頼性のため、運営者情報・返金方針は掲示しておくのが無難です（`/legal` ページに雛形あり。個人の場合、住所は「請求があれば開示」とする方法があります）。
- 個人情報保護法：プライバシーポリシーが必要です。海外の寄付者がいる場合、EU の GDPR 等も影響します。
- 掲載団体の審査：架空の団体による詐欺を防ぐため、登記・代表者の本人確認を必ず行ってください。

## 6. 法人化のタイミング

- 寄付額が増えたら、**一般社団法人 → 公益認定** または **NPO法人 → 認定NPO** を検討。運営者自身が控除対象の受取先になれます。
- 法人化すると Stripe・銀行の審査も通りやすくなります。

## 推奨する立ち上げ順

1. まず日本国内の **自治体・社会福祉法人など、自前の口座と領収書発行ができる受取先** を数件確保する。
2. 各受取先に Stripe Connect（Express）アカウントを作ってもらう。
3. Stripe にプラットフォームとして申請し、テストモードで全フローを確認。
4. 専門家に規約・資金の流れを確認してもらってから本番公開。
5. 海外の受取先は、国ごとの Stripe 対応を確認しながら追加する。
